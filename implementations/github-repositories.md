# High-Quality GitHub Implementations

- **[LightersWang/Awesome-Active-Learning-for-Medical-Image-Analysis](https://github.com/LightersWang/Awesome-Active-Learning-for-Medical-Image-Analysis)**  
  *Relevance:* Comprehensive code and paper repository providing evaluation scripts for benchmark active learning algorithms on medical image classification and segmentation.
- **[oligogenic/Deep_active_learning_bioRE](https://github.com/oligogenic/Deep_active_learning_bioRE)**  
  *Relevance:* Official PyTorch implementation evaluating six deep active learning query strategies across 7 biomedical relation extraction datasets using PubMedBERT.
- **[cleanlab/cleanlab](https://github.com/cleanlab/cleanlab)**  
  *Relevance:* Python library for dataset curation and Confident Learning that automatically identifies label errors and quantifies annotator noise in supervised ML datasets.
- **[bowang-lab/MedSAM](https://github.com/bowang-lab/MedSAM)**  
  *Relevance:* Segment Anything foundation model adapted for medical imaging, providing interactive bounding-box to mask annotation pipelines for radiologists.
- **[microsoft/annotation-assistant](https://github.com/microsoft/annotation-assistant)**  
  *Relevance:* Microsoft research framework for evaluating zero-shot and few-shot LLM annotations against expert human ground-truth baselines.
