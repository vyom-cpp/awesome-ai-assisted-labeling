# Curated Tools and Libraries for AI-Assisted Data Labeling

- **[Label Studio](https://github.com/HumanSignal/label-studio)**  
  *Purpose:* An open-source, multi-modal data annotation platform featuring machine learning backends that provide real-time model predictions to assist and accelerate human annotators.
- **[Prodigy](https://prodi.gy/)**  
  *Purpose:* A scriptable, active-learning annotation software designed by Explosion AI that prioritizes the most informative data points for human review to minimize manual annotation hours.
- **[Argilla](https://github.com/argilla-io/argilla)**  
  *Purpose:* An open-source data curation platform for LLMs and NLP that combines human feedback, weak supervision, and validation workflows to monitor and improve dataset accuracy.
- **[Snorkel](https://github.com/snorkel-team/snorkel)**  
  *Purpose:* A programmatic weak supervision framework enabling researchers to write heuristic labeling functions to label large-scale scientific datasets without manual token-by-token curation.
- **[CVAT (Computer Vision Annotation Tool)](https://github.com/cvat-ai/cvat)**  
  *Purpose:* A web-based digital image and video annotation platform with built-in AI model inference endpoints for automatic pre-annotation and polygon tracking.
